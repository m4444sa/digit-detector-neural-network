# Neural Network From Scratch

A beginner AI project where I implemented a neural network from scratch using NumPy.

This project was inspired by the **Machine Learning Specialization**
by Andrew Ng and the DeepLearning.AI team.

The project builds on concepts learned through the course and extends
them into a hands-on implementation using NumPy and PyTorch.
## What the project does

The model recognizes handwritten digits from the MNIST dataset.



## Part 1 — Neural Network From Scratch

The first implementation was built without a neural network framework.
